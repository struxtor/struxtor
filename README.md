# Struxtor

Report problems and suggest features for [Struxtor](https://struxtor.com) and its local
program, **struxtor-harness**, here. This repository holds issues only.

- **Something does not work:** [open a bug report](https://github.com/struxtor/struxtor/issues/new?template=bug.yml).
- **An idea:** [suggest a feature](https://github.com/struxtor/struxtor/issues/new?template=feature.yml).

For the harness, run `struxtor-harness feedback`: it fills in the report for you, shows you
what goes in, and asks before opening it in your browser. Or run `struxtor-harness doctor` and
paste its output into the report: it names the version and the server, and holds no token, but
it shows folder paths: check them before you submit.

Please do not paste tokens, passwords or private code into an issue: issues here are public.
